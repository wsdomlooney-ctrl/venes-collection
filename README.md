# Venes Collection Website

A responsive fashion storefront for Venes Collection, designed for GitHub Pages.

## Quick setup on GitHub

1. Create a new GitHub repository named `venes-collection`.
2. Upload everything inside this folder to the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will give you a live website URL.

## Replace the temporary images

The current product and fashion images are temporary online placeholders. You can replace them later by:
- putting your own images in `images/products/`
- changing the `img:` URLs in `js/script.js`
- changing the hero/category image URLs in `index.html`

## Important

Replace `233000000000` in `index.html` and `js/script.js` with the Venes Collection WhatsApp number before launch.

Replace `hello@venescollection.com` and the Instagram placeholder with your real contact details.
